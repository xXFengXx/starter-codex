# 目标

修复知识库中中文提问无法检索已有相关内容的问题。任务 T-001 的用户报告：「Hermes自构建是怎么做的」「什么是AI学习导师」均返回 citationCount=0、confidence=0.3。修复必须恢复有依据的检索与回答，并保持英文提问能力；编码、中文匹配或索引问题均只是待诊断方向，不预先认定根因。

# 范围

- 诊断中文问题从输入、传输、查询处理、检索到回答引用的链路，区分显示编码问题和实际查询内容损坏。
- 在已成功导入、完成索引且确有相关资料的知识库内，修复上述两个中文问题的检索失败。
- 覆盖中英混合查询（含 Hermes）及英文回归，验证无相关资料时仍不伪造引用。
- 本阶段仅编写本目录 contract.md、plan.md、traceability.md；下述产品行为为后续获批实施的验收要求。

# 非目标

- 不以硬编码答案、强制提高 confidence 或伪造 citationCount 掩盖检索失败。
- 不重建检索架构，不新增模型供应商，不开展无关性能优化或依赖升级。
- 不修改 harness/**、AGENTS.md、CLAUDE.md、.github/** 或任何门禁；不迁移持久化格式，不操作真实用户数据。

# 约束

- 当前 state.json 为 intake，本阶段不转换状态；产品实施必须取得人工批准并满足流程要求。
- 依赖已通过 node_modules junction 就绪；禁止运行 npm ci / npm install，不删除、重装或替换 node_modules。
- 后续实现遵守 TypeScript 严格模式、命名导出、统一 IPC 定义和 Service 注入约定。
- 测试仅使用 .harness/runtime/ 中的隔离资料和索引，不读写真实 Electron userData。
- 测试资料必须事先包含 Hermes 自构建流程和 AI 学习导师定义，固定预期文档及支持答案的段落；禁止依赖生产知识库、外网或随机生成内容作为判据。
- 不预设特定分词或编码修复方案；依据复现证据选择最小变更。

# 验收标准

- **AC-001**: 在固定、已导入并索引的相关资料上，分别提问「Hermes自构建是怎么做的」「什么是AI学习导师」，两者 citationCount 均大于 0，且至少一条引用指向各自预期文档的支持段落；回答覆盖资料中的流程或定义，不再走 citationCount=0、confidence=0.3 的无命中路径。
- **AC-002**: 上述两条查询经实际输入与检索入口传递后，中文字符及 Hermes 标识无损；逐字符或 Unicode 码点比对输入与检索入口的原始查询值一致。若存在有意规范化，分别记录规范化前后的值并验证未丢失主题词；若发现显示乱码，另行提供字符比对证据，不将显示修复等同于检索修复。
- **AC-003**: 在同一固定资料和索引上，使用英文查询“How does Hermes self-build work?”和“What is an AI learning tutor?”，修复前记录可命中的基线，修复后两者仍各有至少一条预期文档的有效引用，且回答包含相同的资料要点。
- **AC-004**: 对固定资料明确未包含的主题提问时，citationCount 为 0，回答明确缺少依据且不伪造引用；confidence 沿用既有无命中规则，不通过无条件提升分数使正例通过。
- **AC-005**: 在 .harness/runtime/ 的干净隔离测试状态下可重复运行上述场景并获得相同的命中结论；完成契约与追踪校验、check、test、build、范围及敏感信息审查、依赖审计结果审阅记录和 PR Package 生成，保留可复现证据，所有强制门禁通过后才进入审阅。

# 风险

- medium：修复涉及用户可见检索行为，查询编码、规范化或匹配逻辑可能影响英文；以固定双语资料和修复前后对照控制风险。
- 编码或终端显示异常尚未证实；如发现异常，分别采集显示和检索链路证据，避免错误归因。
- 引用数量和置信度不能单独证明正确性；同时核对预期文档、支持段落和答案要点。不新增未经依据的置信度阈值。
- 原始生产资料未提供；先用固定资料复现机制，若无法复现，补充经脱敏的导入和索引条件后再确定修复，不猜测根因。

# 验证预期

- 记录复现环境、编码、资料、索引状态、原始查询、检索入口字符、命中文档、引用和答案要点；保留修复前失败与修复后通过的对照证据。
- AC-001 至 AC-004 使用固定场景自动化验证，并通过应用实际提问链路复核；AC-005 按现有 Harness 执行，不修改或绕过门禁。
- 本阶段只交付计划，所有验收结果为待处理，不声称产品已修复或产品门禁已通过。本阶段的文档检查记录见 plan.md；不运行依赖安装或产品验证。
